P03：五个 L1 任务的可复现随机初态（2026-10-18）

入口：l1_position_perturbations_p03_20261018.json。
默认任务配置启用 initial_placement_profile = "l1_xy_random_p03_20261018"，
默认选定布局已调整为：L1-01 第3组、L1-02 第3组、L1-03 第2组、L1-04 第1组、L1-05 第1组。
initial_placement_variant 可设为 1～5 来选择对应布局；
将 profile 改为 "baseline" 可恢复原始摆放。P01/P02 文件仍可使用。

这些布局是从原始基准独立抽样后冻结的，不在 P01/P02 上累积。
每个任务、每组有独立种子；同一实验重置时保持布局，避免实验中途改变环境。
主种子为 20261018，通过 SHA256(master_seed:task_id:variant) 派生各组的种子。
移动方向在 360° 内抽样；半径按圆环面积均匀抽样。
各物体组独立抽取方向和距离；经过明确约束后的可行分布并非无约束均匀分布。
帽子转角正负等概率，绝对值在 10～25° 之间均匀抽样。

L1-01：笔 3～7cm，杯子 2～5cm。
L1-02：插头和黑色底座整体 3～7cm，插排 2～5cm。
L1-03：帽子和蓝盒整体 3～7cm，挂架 0～3cm；帽子绕移动后的盒子中心转动。
L1-04：两杯各自 3～6cm，左右不交换，前后差 1～5cm；桌面中心目标不动。
L1-05：源杯、花、充电头、独立叶片整体 3～7cm；目标杯和十颗玻璃珠整体 3～7cm。
        花所在杯子保持画面右侧；两个杯子在摆放后仍固定。

抽样过滤：桌面边界留 10mm；独立组 XY 包围盒至少留 5mm（挂架使用实际分段碰撞体的投影多边形，保留三条腿之间的空隙）；
两组的相对偏移变化至少 15mm；保持杯子的角色和左右关系；
除原本就裁切顶部的挂架外，移动物体的完整包围盒须位于全局画面内并留 8px 边距；
关键操作区域的位置 IK 误差不超过 3mm。
位置 IK 仅筛查关键区域的可达性，不验证抓取姿态或完整无碰撞轨迹。
离线过滤日志、IK 结果、尝试次数均保存在 JSON 中。
被动物理检查发现的无效候选记录在 l1_position_perturbations_p03_rejections_20261018.json，
重新生成时按记录过滤这些候选；原始结果与配置快照保存在 build 目录中以供复核。

被动仿真检查另行验证：静置支撑、初始机器人碰撞、物体滑动、
关键物体位于画面中、初始评分保持 running、L1-05 双杯固定与十颗珠仍在杯内。
这些检查不调用 GPT，不代表正式任务操作成功。

英文提示词、执行臂定义、评分阈值、相机、灯光、资产、质量与碰撞体不变。
位置目标从活动场景变换派生，绝对桌面中心保持基准定义。

重新生成相同样本：
PYTHONPATH=src python tools/generate_l1_position_variants.py --seed 20261018
更换种子将得到一套新样本，必须重新运行被动物理初态检查并更新预览后使用。

启动指定布局。此处仅说明用法，生成预览不会启动 GPT 正式实验。
