# GPT-6 机器人测评流水线

这套框架在 Isaac Sim 中创建机器人任务，让 GPT-6 根据观测自主决定动作，再根据执行结果持续调整，最终自动评分和记录。

**任务与场景 → 固定朝下准备 → 观测 → 模型决策 → 动作检查与 IK 求解 → 物理执行 → 反馈与再次决策。评分和记录贯穿整个过程。**

下面以当前已经接入的单臂方块抓放任务为例，说明每一层负责什么、如何衔接。

## 开始前确定什么

- **任务目标与规则：** 例如拿起方块、搬运到目标区域、松开并撤离。提前确定初始状态、成功条件、失败与复位条件。
- **模型的权限与输入：** 区分操作臂、观察臂和固定臂。当前抓放由左臂操作，右臂可移动腕部相机寻找视角，但不能收到夹爪指令；明确模型能看到哪些图像、状态和反馈。
- **实验预算：** 固定模型版本、思考强度、决策次数和时间上限，方便重复测试和比较。

## 一次任务怎样运行

1. **创建场景：让机器人和物体具备可计算的物理属性。**

   加载 R5 双臂、两指夹爪、桌面、方块和目标区域，设置初始位置。机器人资产描述关节连接关系和运动范围；物体设置尺寸、质量、碰撞形状和摩擦等参数，这些决定它们如何运动和接触。相机设置第三视角和两个腕部视角，腕部相机随机械臂运动。

   复位后，操作臂先移动到固定朝下准备位姿，保持原夹爪开口；观察臂保持复位姿态。准备不参考物体位置，单独记录并消耗仿真与现实时间；到位后才开始评分与模型决策，失败则停止。

2. **采集观测：把场景变成模型能使用的信息。**

   三路相机提供同一仿真时刻的 RGB 与深度，同时读取关节角、夹爪开口和末端实际位置。模型按次接收图像，并结合此前的文字记录理解过程。所有任务固定提供相机参数和坐标标记，无需在任务配置中启用，也不设关闭开关。

   内参描述图像如何投影，外参描述相机在场景中的位置和朝向；结合像素深度，可以换算出可见表面的三维位置。这里使用的是虚拟相机参数，深度也是仿真输出，尚不等同于真实相机的标定和测量误差。

3. **模型决策：把“看到的情况”变成“下一步动作”。**

   通过接口把任务指令、观测和历史执行反馈交给 GPT-6。GPT 自主决定抓哪里、如何接近、何时夹紧、如何搬运和放置，并返回末端目标位置、朝向和夹爪开口。末端是夹爪上的控制参考点，通常称为 TCP。每次决策附带简短的观察与动作说明。

   看不清时，GPT 可以移动获准的观察臂调整腕部相机视角，仍走同一个动作与反馈接口。也可查询图像中某个像素的深度与三维位置；查询本身不移动机器人。查询得到的是可见表面位置，抓取位置仍需模型判断。观察动作、深度查询与操作动作共用调用和时间预算。

4. **动作检查与 IK：把末端目标变成关节目标。**

   框架先检查动作格式、机械臂权限和参数范围，再统一坐标定义。Lula IK（逆运动学）根据 R5 的结构、当前关节角和关节限位，计算“要达到这个位置与朝向，每个关节应该转到多少度”，并检查求解误差。夹爪开口单独转换为手指关节目标。

   动作不合法或没有求得合格的解时，框架拒绝执行并返回原因。IK 给出目标关节姿态；当前链路没有自动避障路径规划，沿途运动仍可能发生碰撞。

5. **物理执行：让机器人实际运动并与物体接触。**

   关节驱动追踪目标角度。刚度决定偏离目标时纠正的强弱，阻尼用于抑制振荡；物理引擎逐小步计算重力、碰撞、摩擦和接触。当前同一动作同时要求移动与开合夹爪时，会先等待机械臂到位稳定，再执行夹爪动作。

   抓得住、是否滑落、能否放稳，都由运动和接触结果体现。等待 GPT 回复时，物理仿真暂停；模型决策频率与物理引擎计算频率分开。当前模型可控制位置、朝向和夹爪开口，尚未接入力觉输入或直接力控动作。

6. **执行反馈：判断动作实际做成了什么，再交回模型。**

   框架读取实际关节角、末端位置和夹爪开口，与目标比较；到位稳定或达到单动作执行上限后，返回结果和新画面。反馈包括位置误差、是否到位、超时或动作被拒绝等。

   GPT 根据这些信息选择下一步。例如夹爪被物体挡住、未闭合到目标开口时，模型需要结合画面判断是否已经抓住。随后重新进入“观察—决策—执行”循环。

7. **任务评分与结束：检查完整目标是否达成。**

   评分器根据仿真中的物体位置、接触和稳定性等实际状态持续判断。方块抓放会检查是否抓持抬起、是否放到目标区域、是否释放并保持稳定；机器人到达某个目标位置并不直接代表任务成功。

   成功、模型请求停止、预算耗尽或不可继续的错误都会结束运行。框架支持保留历史的复位重试，但需要任务定义可重试的失败条件并启用；当前抓放没有接入自动复位。重新启动独立测试会清空历史，最终成功与否由评分器判定。

## 结束后得到什么

运行过程中同步保存观测、模型动作、执行反馈、评分和三路录像；结束后汇总本次结果与实验设置。

- **结果报告：** 是否完成、模型决策次数、真实耗时、仿真耗时及重试情况。
- **全过程录像：** 包含失败尝试，用于检查抓取、搬运和对准过程；等待接口的时间单独计入耗时。
- **过程记录：** 用于区分问题发生在模型判断、IK 求解、动作执行还是物体接触阶段。

多次独立运行后，再汇总成功率和典型失败案例；首次尝试成功与复位后成功分别统计，服务故障单独说明。

目前已接入单臂方块抓放和 L1-01～L1-08 的场景与评分；这不代表八项任务已通过 GPT 测评。增加新任务时，需要补齐任务场景、复位和评分规则，其余观测、模型调用、机器人执行和记录流程可以复用。

公共流程默认使用 medium 思考强度、最多 100 次决策；达到成功、停止条件或时间预算时仍会提前结束。任务选择机械臂角色，公共层统一检查权限和固定臂的意外移动，任务评分只判断任务本身是否完成。观察臂“不接触物体”还有赖于模型遵循指令，当前没有完整避障或覆盖全臂的接触违例判定。
