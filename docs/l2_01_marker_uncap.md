# L2-01 双臂拔笔帽：原生马克笔桌面起步

整支黑色马克笔横放在拓境实验室桌面，双手空手。左臂拿起笔身，右臂夹住笔帽并沿轴线拔开；两部分分别落桌并松手即可，不指定落点或末端姿态。

```bash
python tools/launch.py run L2-01 --gui
```

配置为 `configs/tasks/l2_01_marker_uncap.toml`，复用公共 GPT 工作流。资产来自锁定的 `tabletop_interactions_20261006`：笔长约 151 mm，笔身直径 16.2 mm，笔帽外径 17.4 mm；笔帽接触阻力由原生四个被动径向弹簧垫和摩擦产生，不将笔或笔帽绑定到机械臂。采用 1920 Hz 物理步长。

评分要求先有整笔抬升，再有双手持握下的分离，最后分别获得桌面支撑并释放。支撑阈值按部件质量计算（笔身 17 g、笔帽含垫约 5 g）；允许圆柱绕自身长轴自转，不把这种自转误判为放置失败。

这是 `l2-01-native-marker-v1`，不能与旧版程序生成道具的成绩直接合并。供应方 Sharpa 固定笔身验收及本项目夹具拉脱测试均不代表 R5 双臂或 GPT 已完成整个任务。材料损伤和真机拔出力尚未标定。
