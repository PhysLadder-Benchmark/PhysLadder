# L2-01 双臂拔笔帽：绿盒起步

```bash
python tools/launch.py run L2-01 --gui
```

151 mm 黑色马克笔横放在双臂中间的绿色盒子中心，第三视角看笔帽朝右、笔身朝左。盒外尺寸 190×200×100 mm，中央承托面高 93.5 mm。双方空手，左臂拿起笔身，右臂沿轴线拔帽；左右按第三视角命名，对应真机右臂拿身、左臂拔帽。

完成要求：双臂操作使笔帽完全脱离笔身，评分确认实际分离后立即成功。允许继续夹持；不要求放下、释放、稳定等待或双臂回位。支撑力与转速只保留为诊断，不作为完成门槛。

配置 `configs/tasks/l2_01_marker_uncap.toml` 复用公共相机与模型流程。新版来源 `feishu_marker_20261011`；保留原生独立 Body/Cap、四个被动径向弹簧垫。笔身直径 16.4 mm、17 g；帽直径 17.6 mm、含垫约 5 g。物理步长为 1920 Hz，摩擦与拔出阻力没有真机标定，材料损伤不在评分内。

盒缘接触修复只应用于 L2-01：绿盒采用五块有实体厚度的凸碰撞体，保留源资产外轮廓、93.5 mm 凹面、100 mm 盒缘和凹面开口宽度，省略装饰槽及内角圆弧。笔帽仅与该盒接触时使用圆柱包络，避免空腔和细碎分块产生相互冲突的接触；笔帽与笔身、内部弹簧垫、机械臂夹指仍用原生碰撞体。包络不允许盒缘进入笔帽空腔或帽顶装饰凹槽。可见资产、质量、惯量和接触材料不变；源 USD 未修改，运行记录的 `physics_overrides.marker_box_contacts` 会记录该近似。

新版本 `l2-01-detach-contact-v5` 与此前物理版本分开统计。接触诊断不调用 GPT，不计入任务成功率：`python -m robot_tasks.integrationtest.diagnostics.marker_contact --baseline`。源资产 Sharpa 验收与本机物理检查不等于 R5/GPT 完整任务成功。
