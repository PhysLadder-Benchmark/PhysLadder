# L2-01 双臂拔笔帽：桌面横放起步

完整马克笔横放在桌面，双手空手；左手自主拿起并稳定黄色笔身，右手抓住蓝色笔帽沿轴线拔开，最终将两部分分别放到桌面并松手。两臂均可操作，三路相机均作为观测输入。

```bash
python tools/launch.py run L2-01 --gui
```

配置为 `configs/tasks/l2_01_marker_uncap.toml`。任务沿用公共 GPT 工作流、medium、100 次总调用、RGB-D、相机参数和标记、深度查询、cuRobo、错误重试、录像与独立评分。

笔身直径 30 mm、长度 120 mm，笔帽外径 42 mm、长度 60 mm，初始重叠 20 mm。空心笔帽内部用被动柔顺接触和摩擦产生配合阻力；没有自动脱扣或把物体绑定到夹爪的逻辑。

评分要求从桌面实际拿起整笔，随后双侧持握、笔身末端从帽口退出至少 8 mm 且接触消失，再将两部分分别稳定放好、双指释放并保持 1 秒。彩色块只是视觉参考，没有指定落点要求。材料损伤未建模，力阈值只是实验代理。

模型仅控制末端位姿和夹爪开口，没有直接力/力矩命令或接触力读数；虚拟接触力只用于独立评分和规划层持物碰撞检查。不能把结果解释为直接力反馈闭环能力。
