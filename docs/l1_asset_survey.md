# L1 asset documentation

The original asset survey describes an earlier task pool, including removed
tasks. It is preserved in [the historical survey](archive/l1_asset_survey.md).
Its task numbers are historical, not current launch IDs.

For the five maintained tasks, see [current L1 tasks](l1_tasks.md) and the
[previous/current numbering map](release/TASK_NUMBERING.md). Runtime source
assets retain their original delivery directories; the task manifests select
the same verified files using current task IDs.
