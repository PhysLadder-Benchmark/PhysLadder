# 当前 L1 仿真任务

维护中的 L1 共六项，均从双手空手开始，左臂操作、右臂可主动调整观察视角。公共输入为三路 RGB-D、相机参数和机器人执行反馈；默认 medium、100 次总调用预算。

| 编号 | 当前道具与布置 | 完成依据 |
|---|---|---|
| L1-01 | 原生白板笔、固定波纹纸杯笔筒 | 笔身与笔帽各自的杯内碰撞体不穿透，杯体承托且已释放，位置/倾斜持续稳定 1 秒；轴向自转不单独拒绝完成 |
| L1-03 | 原生 USB 充电器、固定插线板中间双孔 | 两片倒角插脚分别进入对应孔至少 15 mm，外壳肩部落座，释放承托稳定；保留 0.55 mm 最小单侧间隙 |
| L1-05 | 柄部外露的钥匙代理与矩形锁孔 | 抓起、正确插入并稳定；不转动，可保持夹持。本轮按要求保留代码和配置、不改不测 |
| L1-07 | 原生黄色空顶帽、固定 82 cm 木质挂架最低杆 | 圆头挂杆穿过原生帽圈，指定杆提供向上承托，整帽离桌且已释放即成功，无稳定等待 |
| L1-08 | 两个原尺寸波纹纸杯 | 按分段杯壁/杯底检查真正套入，不穿透，释放后下杯承重；两杯相对位置/倾斜与下杯世界位置持续稳定 1 秒，不因绕轴自转失败 |
| L1-09 | 原生刚体玫瑰、固定波纹纸杯 | 按四段弯折茎胶囊检查入杯与穿透，原生花头碰撞体在杯沿上方，杯体承托且已释放，位置/倾斜稳定 1 秒 |

几何容差沿用原值：笔/玫瑰 1 mm、套杯 1.5 mm、插脚 0.15 mm，没有通过放大容差掩盖碰撞差异。原生碰撞体摘要在 `assets/tuojing/l1_scoring_geometry.json`，启动时与导入后的 USD 几何核对；资产源文件不修改。圆柱/胶囊表面离散误差从接触容差中扣除，不额外放宽。

笔、套杯、玫瑰的稳定窗口检查位置漂移不超过 1 mm、轴向倾斜变化不超过 0.02 rad，持续承托且无夹指接触。轴向自转允许；明显平移或摆动仍会重启窗口。插头与钥匙保持原速度稳定门槛；L1-07 挂帽无等待。抓持抬升过程仍独立记录，L1-03/08/09 的最终完成不依赖历史采样恰好记录到抬升；L1-05 的历史条件保持不变。

帽子的帽圈与帽檐较薄，不能以 12 mm 最小夹爪开口单独夹取。四个 45 mm 高被动支撑垫托住帽圈，给帽檐下方留出约 25 mm 空间，可跨帽檐下表面与前侧帽圈上沿抓取。帽子与挂架不缩放，无预抓持、隐藏约束或自动套挂。规划器使用各段帽圈/帽檐表面，避免包围盒封闭帽圈。实际 GPT 成功率需另行实验；场景/承托诊断不等于机器人完成任务。

`configs/tasks/` 中每项包含启动命令与中文 `description`。例如在仓库根目录：

```bash
python tools/launch.py run L1-01 --gui
```

同一任务的实验配置副本用 `*.local.toml`，通过 `--config` 显式选择，避免注册为第二个同名任务。几何和评分在 `tasks/bench/l1.py`、`scoring_l1.py`，不会因修改 TOML 描述文字而改变。

刚性任务使用抓持抬升核验；柔性花材使用接触观察模式，避免将刚性表面共动假设套到形变物体。仍由 GPT 决定如何操作，评分器不向模型提供物体真值。

软茎是分段弯曲代理，不模拟真实植物的压伤或断裂。插头/钥匙为放大的几何测试件，不代表特定商业接口。项目几何参数均须另行与真机实物核对；场景启动通过不代表 GPT 成功或仿真与真机等价。

旧 L1-02、L1-04、L1-06 不在当前任务池；历史运行记录与旧几何库仍保留，不混入当前任务结果。
