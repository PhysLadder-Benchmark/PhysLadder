# 当前 L1 仿真任务

维护中的 L1 共六项，均从双手空手开始，L1-01/03 按初始 TCP 距物体的距离选操作臂，另一臂观察（当前布局右操作、左观察）；其余任务左操作、右观察。公共输入为三路 RGB-D、相机参数和机器人执行反馈；默认 medium、100 次总调用预算。

L1 的道具、摆放和成功判据沿用 master 的任务设计；相机、模型调用、控制执行与记录使用本地公共流程。所有 L1 沿用公共 overview，不保留 L1-03 的独立相机覆盖。资产从 `assets/tuojing/source/<任务编号>/` 加载：L1-01 使用 `marker/` 和 `mug/`，L1-03 使用 `plug/`、`power_strip/` 和 `plug_base/`。新陶瓷杯与插头底座来自已锁定的本地交付包；当前发布清单尚未覆盖该包，换机器需先安装，不能退回旧纸杯或省略底座。

|---|---|---|
| L1-01 | 左侧固定黑色陶瓷杯、右侧竖立原生白板笔 | 笔任一端实际进入主杯腔且不明显穿透，超过既有 1 mm 数值边界；可继续夹持，也允许松手掉入，无承托或稳定等待要求 |
| L1-03 | 左侧横向固定插线板、右侧黑色底座内竖立的 USB 充电器 | 两片倒角插脚分别实际进入对应中间孔，超过既有 0.15 mm 数值边界，无明显孔壁/孔底/外壳穿透；可继续夹持，无 15 mm 深度、落座、释放或稳定等待要求 |
| L1-05 | 柄部外露的钥匙代理与矩形锁孔 | 抓起、正确插入并稳定；不转动，可保持夹持。本轮按要求保留代码和配置、不改不测 |
| L1-07 | 原生黄色空顶帽、固定 82 cm 木质挂架最低杆 | 圆头挂杆穿过原生帽圈，指定杆提供向上承托，整帽离桌且已释放即成功，无稳定等待 |
| L1-08 | 两个原尺寸波纹纸杯，按真机图左源杯、右接收杯，左右相距 30 cm，右杯靠前 2 cm（照片估计） | 按分段杯壁/杯底检查真正套入，不穿透，释放后下杯承重；两杯相对位置/倾斜与下杯世界位置持续稳定 1 秒，不因绕轴自转失败 |

几何容差沿用原值：笔/玫瑰 1 mm、套杯 1.5 mm、插脚 0.15 mm，没有通过放大容差掩盖碰撞差异。原生碰撞体摘要在 `assets/tuojing/l1_scoring_geometry.json`，启动时与导入后的 USD 几何核对；资产源文件不修改。圆柱/胶囊表面离散误差从接触容差中扣除，不额外放宽。

套杯、玫瑰的稳定窗口检查位置漂移不超过 1 mm、轴向倾斜变化不超过 0.02 rad，持续承托且无夹指接触。轴向自转允许；明显平移或摆动仍会重启窗口。钥匙保持原速度稳定门槛；笔与插头只检验实际进入，释放、承托和运动为诊断指标；L1-07 挂帽无等待。抓持抬升过程仍独立记录，L1-03/08/09 的最终完成不依赖历史采样恰好记录到抬升；L1-05 的历史条件保持不变。

帽子的帽圈与帽檐较薄；L1 独立机器人配置允许 0–70 mm 名义开口，实际能否夹住仍需接触及抬升验证。四个 45 mm 高被动支撑垫托住帽圈，给帽檐下方留出约 25 mm 空间，可跨帽檐下表面与前侧帽圈上沿抓取。帽子与挂架不缩放，无预抓持、隐藏约束或自动套挂。规划器使用各段帽圈/帽檐表面，避免包围盒封闭帽圈。实际 GPT 成功率需另行实验；场景/承托诊断不等于机器人完成任务。

`configs/tasks/` 中每项包含启动命令与中文 `description`。例如在仓库根目录：

```bash
python tools/launch.py run L1-01 --gui
```

同一任务的实验配置副本用 `*.local.toml`，通过 `--config` 显式选择，避免注册为第二个同名任务。几何和评分在 `tasks/bench/l1.py`、`scoring_l1.py`，不会因修改 TOML 描述文字而改变。

当前维护中的 L1 道具均按刚体处理，执行层使用抓持抬升核验。仍由 GPT 决定如何操作，评分器不向模型提供物体真值。

L1-09 使用原生分段茎刚体玫瑰，不模拟真实植物形变、压伤或断裂。插头保留原生尺寸（最小单侧间隙 0.55 mm），钥匙仍为简化几何测试件。项目几何参数均须另行与真机实物核对；场景启动通过不代表 GPT 成功或仿真与真机等价。

旧 L1-02、L1-04、L1-06 不在当前任务池；历史运行记录仍保留；旧任务实现已移除，不混入当前任务结果。
