几何容差沿用原值：笔/郁金香 1 mm、套杯 1.5 mm、插脚 0.15 mm，没有通过放大容差掩盖碰撞差异。原生碰撞体摘要在 `assets/tuojing/l1_scoring_geometry.json`，启动时与导入后的 USD 几何核对；资产源文件不修改。圆柱/胶囊表面离散误差从接触容差中扣除，不额外放宽。

五项对齐任务检查真实进入、独立承托和释放；仅在指令要求时检查回位。挂帽允许自然晃动、无额外等待，其余以 1 秒、5 mm 位移和 5 度倾斜变化验证稳定，轴向自转本身不拒绝成功。记录正确操作臂接触，不额外要求抬升 15 mm 或 TCP 包络间距 15 mm。完整来源、冲突取舍及尚未复现的条件见 [当前对齐说明](l1_real_alignment_20261012.md)。这些是仿真验证容差，不是真机实测精度。L1-05 的任务目标和评分保持不变，左右臂实体命名随 L1 公共配置一起对齐。

帽子的帽圈与帽檐较薄；L1 独立机器人配置允许 0–70 mm 名义开口，实际能否夹住仍需接触及抬升验证。原生 190×200×100 mm 青绿色盒子提供被动承托；根据实际外露帽檐或帽圈上沿选择抓点。帽子按 2026-10-13 真机图等比缩为原估计模型的 80%（约 188×238×69 mm），视觉、碰撞和评分几何同步；盒子与挂架尺寸不变，无预抓持、隐藏约束或自动套挂。规划器使用各段帽圈/帽檐表面，避免包围盒封闭帽圈。实际 GPT 成功率需另行实验；场景/承托诊断不等于机器人完成任务。

`configs/tasks/` 中每项包含启动命令与中文 `description`。例如在仓库根目录：

```bash
python tools/launch.py run L1-01 --gui
```

同一任务的实验配置副本用 `*.local.toml`，通过 `--config` 显式选择，避免注册为第二个同名任务。几何和评分在 `tasks/bench/l1.py`、`scoring_l1.py`，当前真机摘要协议由 `real_l1.py` 和 `resolve_bench_spec` 应用，不会因修改 TOML 描述文字而改变。
