# 当前 L1 仿真任务

维护中的 L1 共六项，均从双手空手开始，左臂操作、右臂可主动调整观察视角。公共输入为三路 RGB-D、相机参数和机器人执行反馈；默认 medium、100 次总调用预算。

| 编号 | 当前道具与布置 | 完成依据 |
|---|---|---|
| L1-01 | 桌面竖直马克笔、固定宽口笔筒 | 自主抓起，入筒至少 40 mm，笔筒承重，释放稳定 |
| L1-03 | 矩形插舌代理、固定宽松插座 | 方向、插入深度、释放与支撑均满足 |
| L1-05 | 柄部外露的钥匙代理与矩形锁孔 | 抓起、正确插入并稳定；不转动，可保持夹持 |
| L1-07 | 小号带柄硬杯与固定上弯挂杯钩 | 钩穿过杯把，实际承重，离桌释放稳定 |
| L1-08 | 两个无柄空心杯，分开放置 | 抓起上杯并宽松套入，下杯承重，释放稳定 |
| L1-09 | 被动弹簧连接的软茎与重花头代理、固定花瓶 | 抓起、茎端进入瓶内、花瓶承重且释放稳定 |

所有杯口、孔口和杯把都有开放碰撞几何。任务完成由真实位置、方向、接触和过程记录判定，模型声称完成不会直接得分。默认要求最终状态连续稳定 1 秒；夹爪受阻不是抓取成功证据。

`configs/tasks/` 中每项包含启动命令与中文 `description`。例如在仓库根目录：

```bash
python tools/launch.py run L1-01 --gui
```

同一任务的实验配置副本用 `*.local.toml`，通过 `--config` 显式选择，避免注册为第二个同名任务。几何和评分在 `tasks/bench/l1.py`、`scoring_l1.py`，不会因修改 TOML 描述文字而改变。

刚性任务使用抓持抬升核验；柔性花材使用接触观察模式，避免将刚性表面共动假设套到形变物体。仍由 GPT 决定如何操作，评分器不向模型提供物体真值。

软茎是分段弯曲代理，不模拟真实植物的压伤或断裂。插头/钥匙为放大的几何测试件，不代表特定商业接口。项目几何参数均须另行与真机实物核对；场景启动通过不代表 GPT 成功或仿真与真机等价。

旧 L1-02、L1-04、L1-06 不在当前任务池；历史运行记录与旧几何库仍保留，不混入当前任务结果。
