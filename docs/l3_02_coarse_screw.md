# L3-02 双臂旋下预松螺母

```bash
python tools/launch.py run L3-02 --gui
```

保留配置名 `configs/tasks/l3_02_coarse_screw.toml`，当前任务是旋下螺母，历史旋入任务不再作为此入口。

新版 `feishu_bolt_20261011` 提供独立 140 mm 锥尾螺杆和 24 mm 对边六角螺母。组件横置两臂中间的绿盒中央，第三视角看杆身朝左、螺母朝右。左臂拿起 14 mm 光杆，右臂夹螺母旋下；双方空手开始，无固定杆身、预抓或同轴辅助导轨。

原生右旋螺纹螺距 2 mm；初始化按相同螺旋关系预松七圈／14 mm，剩 5 mm 啮合，约 2.5 圈。物理碰撞负责螺纹运动，程序不按转角直接推进螺母。

完成要求：拿起杆身，双臂持握时产生实际相对旋转和外移，螺母完全越过杆端脱离。随后两件各自放在盒或桌上释放，允许任意摆放朝向；双臂回到初始关节位置才完成。无指定最终圈数或静止等待。2 度、0.05 mm 是旋转／外移证据的噪声门槛，不是要求模型追踪的目标。

本任务采用 1920 Hz 步进，控制周期仍为 1/12 秒；使用公共实验室 R5 profile 的 0–70 mm 名义开口，零开口与 URDF 关节下限一致，适配新版 14 mm 光杆。开口映射尚未经真机标定。保留原生 SDF、质量与摩擦，未标定真实拧紧力矩、滑牙或损伤。

初始场景检查不调用 GPT：

```bash
python -m robot_tasks.integrationtest.diagnostics.initial_gallery L3-02 --output reports/nut_initial
```
