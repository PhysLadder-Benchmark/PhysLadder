# 候选任务的仿真初筛

核查日期：2026-09-25。任务以[当前飞书执行方案](https://sxavxhkemv.feishu.cn/docx/AteSdzDw8o7uxLxQ7HBcsoYMnQf)中的 24 项为准，保留原编号。原表没有 L2-05、L3-01、L3-02，本轮不补造任务。插花、运水不在这版候选表中，不计入统计。

## 结论怎么读

本表回答“在约五天的窗口内，能否建立保留关键物理机制的仿真测试”，不预测 GPT 能否成功，也不代表已完成真机对齐。

- **可行性较强**：已有相近仿真实现，或主要机制可以用现成刚体接触、关节和驱动构建；仍需本机验证、资产调整和评分实现。
- **短期内难以实现**：按原任务成功标准，还需开发并验证关键机制，例如破损、剥离、卡扣、螺纹啮合。可另做简化版，但应重新命名并说明覆盖范围。

现阶段初筛为 **16 项可行性较强、8 项短期内难以实现**。这是代码审查后的工程判断；实际运行证据见[实验记录](experiments.md)，不能把“有源代码”读成“已经跑通”。其中螺丝任务已有螺纹装配代码基础，完整损伤判据仍待明确。

本机已通过圆柱插入、摩擦受力、弹簧按压、弹性体压缩及 Franka 动作—RGB 基础检查。**当前螺纹实验没有验证出可靠旋转推进，不能据此把螺丝列为已可执行任务。** 这些小实验都不等于完整候选任务已经实现。

“可行性较强”表示单项适合进入首版候选，不表示五天内能同时实现全部 16 项。

## 建议怎样收敛首批任务

| 优先顺序 | 具体任务 | 下一步实现内容 |

| 随后扩展 | L2-07 变阻力抽屉推拉 | 复用已有抽屉代码；将已验证的受力记录接入滑轨和阻力档位，单独验证抽屉完整机制。 |
| 保留候选 | 弹性体夹持；L3-05 螺丝 | 前者需接受“形变阈值”的任务定义，不能直接叫面包无损夹持；后者先完成螺纹机制验证。 |

这份排序用于缩小实现范围，尚未替团队确定真机最终任务。其余标为“可行性较强”的任务不因此视为已经完成或必须全部实现。

## 不阻塞初筛、但正式测评前要对齐的内容

- 当前输入设想是 RGB＋指令，而 L2 多处写了“根据力反馈”。需明确力是只供隐藏评分器记录，还是也提供给模型；两种实验应分开命名。
- R5 SDK 是否能调节夹持力、关节力矩或阻抗尚未确认。仿真能设置这些量，不代表真机有同样动作接口。
- 本轮先验证物体机制。R5 的模型、关节限位、夹爪尺寸、相机视角和工作台还未完成一比一适配。
- 原表中“不压坏、无损坏、无过力”需要转成可测阈值或明确的损伤事件，不能只凭视频主观判定仿真保真度。
- L2 总体定义与部分任务“给定夹持点”的设定还需统一；本轮保留原任务，不擅自改变模型已知信息。
