# 重建证据与复算

本目录保留 37 张输入图像（29 个最新视频采样帧与 8 张测量照片）、COLMAP 稀疏模型、取点坐标、优化脚本和结果。
`frames/old_*.jpg` 是旧视频的视觉核对证据，不并入最新布置的几何求解。

复算应使用独立 Python 环境安装 requirements.txt，避免修改 Isaac Sim 环境：

1. `metric_fit.py`：从 COLMAP 模型拟合桌面，并用桌边及 1.63 × 0.78 米定尺度。
2. `constrained_ba_v2.py`：加入桌高、地面、墙面和原始 R5 CAD 特征点约束。打印与保存收敛状态。
3. `fit_assets.py`：输出机械臂、支架的拟合结果和投影叠加图。
4. `prepare_scene.py`：将求解结果写入上一级参数文件。它会更新参数与纹理，应先保存当前版本；它需要原始资料目录存在以更新源文件索引。最终交付的桌面材质使用另行截取的干净照片纹理，故运行此步会替换该材质。

现有 sfm/0 是已经求解的模型。若要从头做特征提取，`reconstruct.py` 使用 frames/ 与原始 JPG，需原始目录可用。

所有残差都是所选观测和模型约束下的拟合残差，并不是对真实安装坐标的独立计量认证。RGB 手工取点、iPhone Measure 和弱视差都会带来误差。


最终装配修订：主场景在多视角求解后，按用户要求将两底座 yaw 固定为 −90°、前后位置与肩肘折叠姿态对齐，并用新增 STEP 安装腕部相机固定座，估计两腕 roll 为 +90° / −90°。运行 prepare_scene.py 会覆盖这些最终修订；复算请在副本中进行。CAD 转换入口为 ../mounts/convert_step.py。

V4 桌子已按用户确认改为 1.70 × 0.90 × 0.78 m；本目录束调整结果仍按 V3 旧尺寸求解，不代表 V4 定位精度。
