## L1-01 白板笔入固定黑色陶瓷杯

配置仍为 `configs/tasks/l1_01_cylinder_insertion.toml`。2026-10-09 起使用原生黑色白板笔
（高约 151 mm、笔身直径 16.2 mm、最大宽约 18 mm、质量估计 22 g）与新增黑外白内

当前布局为右臂操作、左臂观察。目标是杯腔，不是杯把孔。

布局参考真机实验照片：从桌前朝双臂看，杯在左、笔在右，前后齐平，杯把朝桌前，
笔带帽竖立。杯底原点为 `(0.04, 1.22, 0.78)` m，笔初始底部为
`(0.34, 1.22, 0.781)` m；杯绕 Z 轴转 -90°，中心间距 30 cm。
这些位置按照片比例估计，未做相机标定或实测复原。真机杯子自由放置，仿真仍沿用
固定容器协议；这次更新没有更改机械臂基座或初始关节角。

完整新包安装在 `source/desktop_additions_20261009/`，杯子入口为
`assets/black_ceramic_mug/black_ceramic_mug.usda`。圆柱承台与插头底座也已注册，
分别接入 L2-06 和 L1-03。安装与共享范围见 [PUBLISHING.md](PUBLISHING.md)。

适配记录在场景报告中：笔身圆底胶囊在运行时替换为半径 8.1 mm、高 111 mm 的
平底圆柱，笔帽保持原状；杯子保留全部 657 个原生复合碰撞体，包括分段杯壁、
杯底、底圈与杯把。杯体静/动摩擦沿用新包的 0.55/0.44，恢复系数沿用任务的 0；
接触距离 0.2 mm，速度求解迭代 4 次。原始 USD 与压缩包均不修改。

当前 L1-01 的 `l1_entry_only_v1` 协议仅要求笔任一端真正进入主杯腔、无明显穿模。
允许继续夹持、运动或倾斜；不要求松手、触底、杯体承重或静置，也无固定角度或
40 mm 深度门槛。评分按真实分段内壁、7 mm 高杯底及 90 mm 高杯口计算，并考虑杯子
朝向；沿用 1 mm 数值接触容差，入杯量须超过该数值边界，以区别杯口平面上的接触。
进入把手孔、停在杯口上方或明显穿透均不算成功。放回桌面或碰倒在桌上允许继续恢复，
掉到桌下仍失败。释放、承托和运动只作为附加指标；旧测试结果的判据不追溯改写。

提示词要求先夹住露出的上方塑料、竖直拔出底座，再移动到中间蓝色双孔。

使用方形像素，不把原 16:9 图像拉伸成 4:3。RGB-D、录像、模型内外参与真实渲染一致，

保留 0.15 mm 数值容差区分进入与面接触，并拒绝孔壁、孔底或外壳明显穿模。
仅对准悬空、碰孔沿、只入一脚或底座内落座都不能误计成成功。

## L1-09 刚体玫瑰插花

直接引用 `artificial_rose`，整株为同一刚体，长约 302 mm、质量约 8 g；
容器使用原生波纹纸杯并固定在桌上。玫瑰初始横放，左臂操作、右臂观察，
模型需自行抓起、调整方向、将茎端放入杯内并松手。

花茎约 2.1 mm；L1 独立夹爪配置允许名义 0–70 mm 开口，但仍需验证实际双指接触。提示词优先选择较宽的花头或花萼，

规划负载以细茎和较宽花头分开近似。没有弯曲弹簧或柔性段。
评分要求真实抓持抬升、茎端入杯至少 25 mm、花头高于杯沿、无手和桌面支撑、
杯体承托且稳定 1 秒；允许自然倾靠杯内壁。

任务 ID 及运行命令仍为 `L1-09`。配置文件名 `l1_09_soft_stem_flower.toml`

`photo_props`、`orange_soft` 三个包，**不包含** `tabletop_interactions`、`book` 以及后来新增的四个包；完整遗漏清单见 `release.json`。

- `photo_assets_20261005.zip`


重复安装会核对已有文件，不覆盖本地修改。更新交付版本时应显式更新锁文件。

在有 `pxr` 的 Python 环境中还可检查 USD 组合和依赖：

```bash
python tools/tuojing_assets.py --usd --report build/tuojing_assets/usd.json
```

这个检查不启动物理仿真、渲染或 GPT，不代表任务运行成功。

需在下一步 Isaac 场景加载时确认。其他缺失文件、绝对路径依赖及包外依赖均报错。

引用时必须指定目标 prim，不能默认按普通单件资产引用。检查结果会保留此项说明。
