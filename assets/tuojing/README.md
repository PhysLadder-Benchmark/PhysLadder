当前 15 项任务使用 `source/<TASK>/scene.usdz`，来自用户提供的 `L1-L3_assets_20261015.zip`。每项完整保留该版本的环境、桌子、机器人、相机和物体。旧 `source/` 已整体备份至本机 `build/reference_alignment_20261015/source_before_latest/`，旧 `packages/` 仅作历史来源；公共实验室检查使用 `source/common/lab/`。

```bash
python tools/install_video_scenes.py /path/to/extracted/L1-L3_assets_20261015
python tools/prepare_video_scenes.py --visual-release /path/to/bowen_visual_r3_20261014 --align-contents

```

需要 `usd-core`、NumPy、SciPy 和本项目；启动仿真仍使用 Isaac Sim 5.1。安装器核对已有原包，拒绝覆盖被修改的本地源文件。`video_20261015.json` 记录每项原包与运行层大小、SHA256、实际物体姿态/尺寸、继承缩放、相机偏移和评分目标；`video_scoring_geometry.json` 记录从新碰撞体导出的几何。运行层清除保存的渲染图和编辑器相机、恢复米制/Z-up/defaultPrim，使用相对原包贴图和 Isaac 内置 MDL，不改变原始 USDZ 字节。动作阶段不通过物体位姿写入或固定约束完成任务。14 项接入 PR #19 的桌纹、背景线缆和环境外观；L3-11 为其明确排除项。该覆盖仅作用于环境，任务物体及材质以 10 月 15 日完整包为准，包括 L1-01 马克笔和 L1-03 黑色托盒、充电器。插花目标杯补入 10 颗同批玻璃珠，倒球源杯补至 10 颗；16 mm 球径、物性和隐藏堆积仍未实测，未编造白珍珠。所有派生内容与来源哈希在清单中单列。瓶盖与螺母场景启用 SDF 所需的 GPU dynamics。

运行层将 6 项任务中的新支撑盒绑定为固定支撑，并移除旧隐藏支撑的重复碰撞；L2-01 将最新笔杆和笔帽分别绑定到原生可分离刚体，修正帽口与笔杆的轴向穿插。L2-03 书本保持动态，以 64/16 次位置/速度迭代改善静置稳定性。L3-03 按用户最新要求固定瓶身；L3-11 白板、字迹和评分坐标共同转向，板擦朝向同步校正。修订和原生空心笔帽等近似保存在 `physical_repairs` 字段。

该包覆盖 15 项有英文定义的任务。完整场景未经过真机尺度、光照或材料标定；PR #19 同样明确保留了弹珠、填充物、线缆和部分初态差异。替换覆盖与视觉/动力学验收是分别记录的检查。

`task_assets.json` 登记每个目录及其原始资产。普通物品的 USD 直接位于物品目录；

`packages/<交付包名>/` 保存完整原始交付，供来源追溯、安装和校验，不作为任务副本的回退路径。
副本缺失或文件被修改会明确报错；更改任务物性仍应通过场景覆盖，而非直接修改锁定文件。

已有旧目录的机器只需执行一次：

```bash

```

该命令校验并将旧的 `source/<交付包名>/` 移到 `packages/`，然后复制各任务所需的物品和依赖。
后续 ZIP 或 Release 安装会自动生成同一布局；再次执行上述命令可核实已有副本。
Combined 版本将当前 `source/` 与 `visual_r3/` 纳入 Git；历史 `packages/` 仍不进入 Git。完整运行资产由 `../runtime.lock.json` 校验。
