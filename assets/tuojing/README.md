## L1-01 白板笔入固定纸杯

配置仍为 `configs/tasks/l1_01_cylinder_insertion.toml`。任务使用原生黑色白板笔
（高约 151 mm、最大宽约 18 mm、质量估计 22 g）和波纹纸杯（高约 107.5 mm、
内口径约 78.6 mm）。左臂自主抓笔并放入杯中，右臂可移动观察，不参与接触。
提示词提醒选择足够高的抓持部位，使夹指在下放、松开时能够避开杯口。

适配明确记录在场景报告中：笔身原胶囊碰撞体底部为圆弧，为使竖立初态自然稳定，
运行时替换为半径 8.1 mm、高 111 mm 的平底圆柱；笔帽碰撞体保留。
纸杯固定，保留 48 段杯壁和杯底形成的空腔；杯壁接触摩擦设为零，抓持和桌面沿用基础摩擦。
保留交付尺寸、材质与贴图，不缩放或改写源文件。纸杯不模拟形变，白板笔和笔帽是同一刚体。

完成需要真实夹持及抬升记录、笔下端进入杯腔至少 40 mm、释放后由杯体承托并稳定 1 秒。
评分采用底部原点与杯腔锥度，避免仅凭 TCP 位置或杯口平面误判。
无 GPT 验收会直接将笔摆入杯内检查承托，这是道具物理检查，不是机器人完成任务的证据。

```bash
# 正式运行，使用项目现有模型配置。
python tools/launch.py run L1-01 --gui

# 工程验收，不读取令牌、不调用 GPT。
python -m robot_tasks.integrationtest.scene_smoke L1-01 --prop-probe --output build/tuojing_l1_01/acceptance
```

工程输出包含三路原始图、深度、带坐标标注的输入预览和 `result.json`。
模型完成率尚未验证；上述验收通过只表明初始场景、准备动作、采集与被动承托正常。

## L1-09 刚体玫瑰插花

直接引用 `artificial_rose`，整株为同一刚体，长约 302 mm、质量约 8 g；
容器使用原生波纹纸杯并固定在桌上。玫瑰初始横放，左臂操作、右臂观察，
模型需自行抓起、调整方向、将茎端放入杯内并松手。

花茎约 2.1 mm，低于当前夹爪 12 mm 最小开口；提示词要求选择较宽的花头或花萼，
不采用交付资产中不适合当前夹爪的细茎抓点。保留原始材质、尺寸和物理碰撞体；
规划负载以细茎和较宽花头分开近似。没有弯曲弹簧或柔性段。
评分要求真实抓持抬升、茎端入杯至少 25 mm、花头高于杯沿、无手和桌面支撑、
杯体承托且稳定 1 秒；允许自然倾靠杯内壁。

任务 ID 及运行命令仍为 `L1-09`。配置文件名 `l1_09_soft_stem_flower.toml`
为兼容已有路径保留，内容、任务名与版本已改为刚体玫瑰。
新验收输出：`build/tuojing_rigid_rose/`；旧柔性版本的诊断记录不作为当前版本证据。

## 安装与校验

从获授权的 L20 连接下载下列文件，并放到项目的 `.cache/tuojing_assets/`：

- `tuojing_lab_20261005_v4.zip`
- `photo_assets_20261005.zip`
- `orange_segment_soft_20261005.zip`
- `tabletop_interactions_20261006.zip`
- `book_physx_20261006.zip`

在项目根目录使用 Python 3.11 或更新版本运行：

```bash
python tools/tuojing_assets.py --archives .cache/tuojing_assets
python tools/tuojing_assets.py
```

第一条校验 ZIP 后安装；第二条逐文件检查已有资产，不需要联网。
重复安装会核对已有文件，不覆盖本地修改。更新交付版本时应显式更新锁文件。

在有 `pxr` 的 Python 环境中还可检查 USD 组合和依赖：

```bash
python tools/tuojing_assets.py --usd --report build/tuojing_assets/usd.json
```

这个检查不启动物理仿真、渲染或 GPT，不代表任务运行成功。
`OmniPBR.mdl` 是 Isaac 内置材质，独立 `usd-core` 无法解析时会单独报告；
需在下一步 Isaac 场景加载时确认。其他缺失文件、绝对路径依赖及包外依赖均报错。
51 cm 备选实验室与两个橘子瓣演示场景没有 `defaultPrim`，可整场打开；作为子资产
引用时必须指定目标 prim，不能默认按普通单件资产引用。检查结果会保留此项说明。

## 接入边界

- 主实验室入口采用约 44.07 cm 双臂轴距；51 cm 版本为备选，不混用两套标定。
- 布局、相机参数、物体质量和摩擦主要为工程估计，不等于真机标定。
- L1-09 已明确改为刚体玫瑰插花；玫瑰和纸杯均不模拟形变。
- 白板笔连同笔帽是一个刚体，不能直接用于拔笔帽任务。
- 插头与插线板已接入并校验配对承托；原生窄间隙比旧宽松代理更难，不可跨版本直接比较成功率。
- 收纳盒已有滑轨；按压解锁、弹出能力需要另行验证和适配。
- 橘子瓣演示使用预设破裂阈值和预切碎块，且破裂会重建场景、重置速度。
  其 GPU 物理与时间步要求见交付说明，不能直接套用机器人任务的默认设置。
